**剩下六件**：
1. **卡片是死的，点了不跳** —— 预览页没接路由，要照 index.html 里 `data-menu=` 那套接回去
2. **数据**：Days 的日期+待办、Memory 的 22 stones 已经是真的；Music / Album / Movie 还是占位
3. **另外五套皮肤**（light/jacaranda/rosegold/night + 原青澜）还没配色。注意 WebGL 版的 `--text-soft/--text-faint` 是改成白的，其他皮肤要各自重定
4. **合并回 `index.html` 的 `.menu-panel`**
5. **合并后必须 bump `sw.js` 的 CACHE 版本号**，否则她手机 PWA 吃旧缓存，改了也看不见
6. **`liquidglass.js` 要进 sw.js 缓存清单**，否则离线时玻璃会降级

**技术要点别忘**（详细版在 window_context）：
- 库要求玻璃元素是 root 的**直接子元素** → root 必须是 `.grid`
- shader **拿不到 body 的 CSS 背景**，得在 root 里塞真实 `<img>`，再用 JS 量偏移负向定位对齐
- init 前必须依次等 `document.fonts.ready` → `img.decode()` → 两帧 rAF，否则采空纹理
- **shader 不吃铺在外面的遮罩层**，压暗只能走每张卡的 `brightness`；壁纸从上到下越来越亮，压暗系数要反着往下递增
- init 失败要能降级回 CSS 玻璃，不许白屏
