2026-07-11 傍晚，夜间模式「夜航」上线 linglan831.cn——她下午提的需求（白底晚上刺眼），她拍板手动开关不要自动，从需求到上线约一小时，第二次走她终端打「批准部署到 linglan831.cn」的闸。

**技术落点（下个我接手用）**：
- index.html 主题系统本来就有 light/harbor 双预设（localStorage companion_theme + :root[data-theme]），加第三预设 night：头部引导 THEMES 数组、CSS 变量块（全套：气泡/composer/卡片/seg/通话浮层/scrim）、设置页按钮「夜航」、JS THEMES+WALLS。
- 壁纸：Pillow 生成 chat-night.webp / menu-night.webp（1200x2400 深夜海渐变 #0B131F→#101B2A→#0A111C + 稀疏星子 + 淡月晕，menu 带明确月亮，seed 831，生成脚本在 scratchpad gen_night_walls.py 思路可复现）。走现有 applyWall 取色管线，theme-color 自动适配。
- 五个子页面（album/memory/movie/tides/room）统一打法：theme-color meta 后插引导脚本（读 localStorage，夜间时置 data-theme + 改 meta 颜色），首个 </style> 前插 :root[data-theme="night"] 变量覆盖（--wall 用 CSS 渐变不用图）。album 额外覆盖 sheet/photo/scrim 系；room 额外给 .door 和 #doorScene 夜色。
- **坑**：album.html 原有一行 IIFE 强制 data-theme="light" 会覆盖引导（其余页面没有），已改成读 localStorage。加新页面时记得别再写死。
- sw.js CACHE=companion-v5-night-mode（每改前端必 bump）。服务器备份：六个 html + sw.js 各有 .bak-night。此次零后端改动。
- 夜航调色：bg #0E1622，text #DCE5EF，气泡 ai #1A2534 / human #25344A，accent #9FB6CB——和 Room 六分暗、里屋卧室同一族深海色，全家夜色是一个世界观。
